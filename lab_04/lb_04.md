## Задание 4.1

Пронумеровать товары по году выпуска (`year`) от новых к старым внутри каждого типа продукта.

**Описание решения:**
Для выполнения задания применена оконная функция `ROW_NUMBER()`.

Нумерация выполняется:

* отдельно для каждого типа товара (`PARTITION BY product_type`);
* в порядке убывания года выпуска (`ORDER BY year DESC`).

Дополнительно в выборке учитываются только товары, которые находятся в производстве (`production_end_date IS NULL`).

Таким образом, внутри каждого типа продукта формируется последовательная нумерация от самых новых моделей к более старым.

## Задание 4.2

Сравнить цену товара (`base_msrp`) со средней ценой двух предыдущих товаров того же типа.

**Описание решения:**
Для вычисления среднего значения использована оконная функция `AVG()` с рамкой:

```
ROWS BETWEEN 2 PRECEDING AND 1 PRECEDING
```

Это означает:

* расчёт выполняется внутри одного типа товара (`PARTITION BY product_type`);
* сортировка ведётся по году выпуска (от новых к старым);
* среднее значение считается только по двум предыдущим записям.

Если для строки недостаточно предыдущих значений (первые позиции в группе), результат среднего значения будет `NULL`, что является корректным поведением оконной функции.

## Задание 4.3

Вычислить нарастающий итог суммы продаж для клиентов из штата `'CA'`.

**Описание решения:**
Для выполнения задания использовано:

* соединение таблиц `sales` и `customers` через `INNER JOIN`;
* фильтрация клиентов по штату (`WHERE c.state = 'CA'`);
* оконная функция `SUM()` для расчёта накопительной суммы продаж.

Нарастающий итог рассчитывается по дате транзакции:

```
SUM(s.sales_amount) OVER (ORDER BY s.sales_transaction_date)
```

Сортировка выполняется по возрастанию даты, что обеспечивает корректное формирование накопительной суммы.
