## Задание 1

Вывести сумму продаж с разбивкой по годам и кварталам.

**Описание решения:**

Для выполнения задания использованы функции работы с датами:

* `EXTRACT(YEAR FROM ...)` — извлечение года;
* `EXTRACT(QUARTER FROM ...)` — извлечение квартала.

Агрегация выполняется с помощью функции `SUM()` по полю `sales_amount`.

Группировка производится по году и кварталу, что позволяет получить квартальную статистику продаж.

```sql
SELECT 
    EXTRACT(YEAR FROM sales_transaction_date) AS year,
    EXTRACT(QUARTER FROM sales_transaction_date) AS quarter,
    SUM(sales_amount) AS total_sales
FROM sales
GROUP BY year, quarter
ORDER BY year, quarter;
```

## Задание 2

Найти клиентов, у которых нет ни одного дилерского центра в радиусе 500 миль.

**Описание решения:**

Для решения задачи использованы геопространственные функции:

* `point(longitude, latitude)` — создание координатной точки;
* оператор `<@>` — вычисление расстояния между точками.

Подзапрос проверяет наличие дилеров в радиусе 500 миль.
Конструкция `NOT EXISTS` позволяет выбрать только тех клиентов, для которых таких дилеров нет.

```sql
SELECT c.customer_id
FROM customers c
WHERE NOT EXISTS (
    SELECT 1
    FROM dealerships d
    WHERE point(c.longitude, c.latitude) <@> point(d.longitude, d.latitude) <= 500
);
```

## Задание 3

Разделить отзывы клиентов на категории и определить количество отзывов в каждой категории.

**Описание решения:**

Для классификации отзывов используется конструкция `CASE` и оператор `ILIKE`:

* `ILIKE` — поиск подстроки без учета регистра;
* `CASE` — распределение отзывов по категориям:

  * `Service` — если встречаются слова *service* или *staff*;
  * `Product` — если встречаются *bike*, *scooter*, *quality*;
  * `Other` — все остальные отзывы.

После классификации выполняется подсчет количества отзывов с помощью `COUNT(*)`.

```sql
SELECT 
    CASE 
        WHEN feedback ILIKE '%service%' OR feedback ILIKE '%staff%' THEN 'Service'
        WHEN feedback ILIKE '%bike%' OR feedback ILIKE '%scooter%' OR feedback ILIKE '%quality%' THEN 'Product'
        ELSE 'Other'
    END AS category,
    COUNT(*) AS total_reviews
FROM customer_survey
GROUP BY category
ORDER BY total_reviews DESC;
```
