# Задания

## Задание 3.1  
Найти дисперсию (VAR_SAMP) цены продуктов.

### Пояснение  
Для решения использована агрегатная функция `VAR_SAMP`, которая вычисляет выборочную дисперсию значений.  
В расчёт включены только те записи, где цена (`base_msrp`) не равна NULL, чтобы избежать искажения результата.  

Дополнительно результат был округлён до двух знаков после запятой для более удобного отображения.

## Задание 3.2  
Посчитать количество дилеров в каждом штате.

### Пояснение  
Используется группировка (`GROUP BY`) по полю `state`, что позволяет объединить дилеров по штатам.  
Функция `COUNT(*)` подсчитывает количество записей в каждой группе.  

Также добавлена сортировка по убыванию количества дилеров, чтобы наиболее представленные штаты отображались первыми.

## Задание 3.3  
Вывести штаты, где суммарная выручка превысила 1,000,000.

### Пояснение  
В данном запросе используется `LEFT JOIN` для объединения таблиц `dealerships` и `sales`.  
Это позволяет учитывать все дилерские центры, даже если у некоторых из них нет продаж.  

Далее выполняется:
- группировка по штатам (`GROUP BY state`);
- вычисление суммарной выручки с помощью `SUM(sales_amount)`;
- фильтрация групп с помощью `HAVING`, так как условие применяется к агрегированным данным.  

Использование `HAVING` необходимо, поскольку обычный `WHERE` не работает с агрегатными функциями.
